# CODEVERSE Systems & Essentials Data

This folder contains all educational data, curriculum syllabus, and standalone executable `.c` programs for the **Systems & Essentials** curriculum track.

## Directory Structure
- `programs/` – 7 runnable standalone systems programming exercises.
  - `01_singly_linked_list_insertion___traversal.c`
  - `02_binary_search_tree__bst__inorder_search.c`
  - `03_process_creation_with_fork___and_exit_reaping.c`
  - `04_multithreaded_counter_with_mutex_lock__pthreads_.c`
  - `05_inter-process_communication_via_anonymous_pipe.c`
  - `06_buffer_overflow_defense_with_snprintf__.c`
  - `07_automated_unit_testing_with_assert__.c`

## Units Covered
1. **Unit 1: Data Structures & Algorithmic Complexity** – Big-O notation, linked lists, binary search trees.
2. **Unit 2: Debugging, Memory Profiling & Tooling** – GDB breakpoints, Valgrind Memcheck, AddressSanitizer.
3. **Unit 3: Build Systems & Toolchains** – Compilers, GNU Makefiles, CMake configuration, static vs shared libraries.
4. **Unit 4: POSIX Systems Programming & Multithreading** – Process fork/waitpid, pthread multithreading, mutexes, pipes.
5. **Unit 5: Software Engineering, Git & Clean Architecture** – Git workflows, automated assertion unit tests, secure coding with snprintf.
