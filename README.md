# CodeViva – Learn. Practice. Grow.

A premier, modern, responsive, and interactive C and C++ programming academy with structured units, interactive quizzes, freeCodeCamp-style step-by-step workspaces, gamified code challenges, and live compilers.

## Key Features
- **Curriculum Architecture**: Comprehensive 5-unit curriculum for both C and C++ programming.
- **Interactive Labs**: Real-time C and C++ execution engine and practical labs.
- **Gamified Learning**: Concept game hub featuring Bug Hunter, Flowchart Runner, Memory Visualizer, and Code Block Sorter.
- **Step-by-step Workspaces**: Guided step-by-step coding lessons.
- **Cross-Platform**: Web application with native Android mobile capability via Capacitor.
